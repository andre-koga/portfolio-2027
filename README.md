# This portfolio has 0 AI in it.

Yeah, you read that right. While I don't think AI is bad,
I just felt like proving to myself that AI does not hinder
my ability to code; I can create by myself, think for myself,
and use my design knowledge to actually create things.

For any questions I had, I used the most ancient of methods:
Googling and StackOverflow. Shocking, I know.

# This website uses the most average stack you can think of

React + React Router 7 + Vite, hosted on Vercel, using TS under the hood.
